# くすりとくらしの情報 Link v0.4

## v0.4
Notionの3DBをWeb実データへ接続する。

- 薬剤マスター
- トピック
- 困りごと

### トップ
- 薬から探す
- 困りごとから探す
- まず知っておきたい

### 薬剤ページ
- 関連トピック
- 関連する困りごと

### トピックページ
- 患者向け要約
- 患者向け対応
- Notion本文の患者向けセクション
- 関連薬剤
- 関連困りごと
- 医療・介護職向け要点

### 困りごとページ
- 患者さんの質問例
- 短い回答
- 緊急度
- 関連トピック
- 関連薬剤

## 公開条件
薬剤・トピック・困りごと:
- レビュー状態 = 完了
- Web公開 = ON
- 最終レビューあり
- slugあり

薬剤のみ追加条件:
- 根拠資料Relationに「資料種別=電子添文」AND「製品区分=先発品」が1件以上

## 重要
Notionで公開ONにしただけでは反映されない。
現行v0.4ではVercelの再デプロイが必要。
