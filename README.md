# v0.9.0 — 薬効群ページ

Notionの薬剤マスターDB `薬効群`（Multi-select）から自動生成。

- `/classes/`：薬効群一覧
- `/classes/<薬効群>/`：薬効群ごとのまとめページ
- 各ページに、その薬効群に属する公開済み薬剤を自動表示
- 1つの薬が複数の薬効群に属する場合、両方のページに掲載
- 薬効群を追加・変更すると、次回Redeploy時に自動反映
- ヘッダーに「薬効群」を追加

現段階では薬効群の解説本文はNotionに新DBを作らず、薬剤マスターから一覧を自動生成する安全な最小構成。
将来、薬効群マスターDBを追加すれば「特徴」「主な作用」「共通の注意点」「関連Q&A」へ拡張可能。
