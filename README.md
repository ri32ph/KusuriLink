# くすりとくらしの情報 Link v0.3.2

## 変更点

公開時の「先発電子添文」判定を文字列検索から構造化判定へ変更した。

### 根拠資料DB
新しいプロパティ:
- `製品区分`
  - `先発品`
  - `後発品`
  - `該当なし`

### 公開条件
薬剤ページは以下をすべて満たす場合のみ生成する。

1. `レビュー状態 = 完了`
2. `Web公開 = ON`
3. `最終レビュー` が入力済み
4. `slug` が入力済み
5. 根拠資料Relation内に
   - `資料種別 = 電子添文`
   - `製品区分 = 先発品`
   を同時に満たす資料が1件以上ある

フォサマック錠35mg／ボナロン錠35mgの電子添文はNotion側で `先発品` に設定済み。

## Build Logs

Vercelのログに以下のような診断が出る。

```text
[PUBLICATION CHECK] 基本公開条件を満たす薬剤: 1件
[EVIDENCE] アレンドロン酸 <- フォサマック錠35mg 電子添文 / 資料種別=電子添文 / 製品区分=先発品
[PUBLICATION CHECK] アレンドロン酸: 先発品電子添文を確認
[PUBLICATION CHECK] アレンドロン酸: 公開対象
```

公開されない場合も理由がBuild Logsに表示される。
